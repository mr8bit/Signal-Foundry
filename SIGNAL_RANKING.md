# Рейтинг сигналов

В Top signals можно выбрать общий рейтинг, модели, GitHub, научные статьи или издания. Тема, поиск и период действуют на выбранную категорию; выбор категории не скрывает остальные колонки ленты. Настройка сохраняется в браузере. Ссылка `/?signals=models&sort=day` сразу открывает модели за сутки.

Enterprise — отдельная пересекающаяся категория Top signals и фильтр ленты: `/?signals=enterprise&sort=day`. Отбираются записи с явными корпоративными признаками в заголовке или первых 1200 символах текста: enterprise/B2B, корпоративное применение, SSO/SCIM/RBAC/SOC 2, управление данными и доступом, on-prem/private cloud/изолированный контур, корпоративные платформы вроде Agentforce, Bedrock или Vertex AI. Общего упоминания API, GPU или имени поставщика недостаточно. Источник сам по себе не определяет категорию. Правила находятся в `signals.ENTERPRISE_RULES`; это эвристика, которая может пропускать материалы без явных признаков. Ранжирование редакционное, причины попадания видны в разборе карточки. Отдельной метрики популярности Enterprise нет.

Редакционный порядок использует формулу `editorial-v4`: тема — до 30, свежесть — 25, конкретика — 15, охват площадок — 15, официальный источник — 5, популярность — 10 (процентиль метрики среди того же источника за 7 дней). Подробности раскрываются кнопкой «Как считаем сигналы»; карточка показывает слагаемые своего балла. Ограничения «одна карточка на источник» больше нет: несколько моделей HF или несколько статей одного издания могут занять соседние места. Следующие места раскрываются кнопкой под рейтингом.

Для трёх категорий доступен порядок по метрике источника:

| Категория | Порядок |
|---|---|
| Модели | Сначала модели с `trendingScore` HF по убыванию; затем модели без него по лайкам. Две группы не сравниваются по сырым числам. |
| GitHub | Звёзды за сутки из GitHub Trending. Общее число звёзд не заменяет эту метрику. |
| Научные статьи | Накопленные голоса HF Papers по убыванию. |
| Издания | Редакционный балл. Сопоставимых счётчиков просмотров/лайков в RSS нет. |

Если метрика отсутствует, запись идёт после записей с метрикой, по редакционному баллу. Ноль — известное значение, а не отсутствие данных. При равенстве метрик учитываются редакционный балл, дата и стабильный ID. Переключение порядка не меняет сам редакционный балл или порядок публикаций Telegram.

Период выбирает записи по времени публикации или появления в трендах. Он не пересчитывает суточные звёзды в недельные или годовые. Голоса Papers и лайки моделей также не являются приростом за выбранное окно. Карточка показывает дату снимка метрики. У сборщика пока нет истории отдельных наблюдений, достаточной для собственного расчёта ускорения GitHub.

Категории строятся отдельно, до объединения дублей внутри каждой коллекции: дайджест со ссылкой на модель не заменяет model card в рейтинге моделей. У каждой записи свой редакционный балл в контексте коллекции, поэтому охват и балл могут отличаться от общего рейтинга. JSON `/api/news` содержит эти списки в `signal_rankings`, а у записей — `signal_categories` и `signal_metrics` с названием метрики, значением, источником и временем наблюдения.

## Сравнение с референсом

Проверено 18 октября 2026 в открытых [highlights.js](https://shir-man.com/homepage/js/highlights.js?v=category-search-20260919-1) и [API ленты](https://shir-man.com/api/feed?github_version=github-momentum-v5&sort=day).

У Denis Trends Top signals объединяет HN и GitHub. HN отбирается по score; при наличии нескольких Show HN они получают отдельные места. Порядок GitHub уже рассчитан сервером. Клиент допускает записи `github-momentum-v5` с согласованными границами окна, положительным `stars_net_gain`, готовым измерением и confidence не ниже 0,8. API возвращает границы окна, baseline/current stars, прирост, ускорение и сведения о качестве измерения. Из этого нельзя восстановить всю серверную формулу и её веса.

Signal сохраняет свою объяснимую формулу и добавляет отдельные рейтинги категорий. Звёзды за сутки берутся готовыми с GitHub Trending; этот показатель не выдаётся за собственное измерение momentum-v5.
