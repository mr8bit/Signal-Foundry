# AI в облаках

В `config.json` добавлены 12 облачных RSS/Atom-лент из списка: Google Cloud AI, Gemini Enterprise и Vertex AI release notes; AWS GenAI, AWS News и What's New; Azure AI, Microsoft Foundry и Azure Updates; Vercel, релизы AI SDK и Cloudflare AI. Категория `cloud` доступна в Top signals, фильтрах ленты, `/api/signals?category=cloud` и `/signals.md?category=cloud`.

## Что становится новостью

Отдельно показываются собственные модели облаков, агентные платформы, новые AI-ускорители/инстансы и количественно подтверждённое снижение цен. Порог заметного снижения — 20% или минимум вдвое дешевле; процент настраивается в `cloud.price_drop_min_percent`. Число из результатов бенчмарка не считается снижением цены. Официальные облачные источники получают те же 5 баллов первоисточника, что и блоги лабораторий.

Объявление о доступности чужой модели становится метаданными `cloud_availability`, а не самостоятельной новостью. В карточке релиза появляется «Где взять» со ссылкой на объявление провайдера; при необходимости указано preview. Дата исходного релиза не меняется, новая доступность не добавляет баллов охвата. Она может появиться и у старой модели, снова попавшей в тренды.

Сопоставление использует семейство, версию и распознанный вариант модели (например, Gemini Pro и Flash различаются) либо точную ссылку на модель Hugging Face. Для карточек HF учитывается исходная дата модели. При неуверенном сопоставлении объявление остаётся в `cloud_pending` и не публикуется отдельно. Когда подходящий релиз появится в архиве, привязка будет пересчитана автоматически. Механизм правил, а не генеративного пересказа: неизвестные названия могут остаться без привязки.

«Где взять» сохраняется в дашборде, статическом HTML, Markdown, компактном JSON, RSS-метаданных и тексте Telegram. Уже отправленные Telegram-сообщения автоматически не редактируются; новое объявление облака не вызывает повторную отправку релиза.

## Правила источников

| Лента | Правило |
|---|---|
| Google Cloud AI | Заголовок анонса или Gemini; затем общий отбор собственных событий/доступности моделей. |
| Gemini Enterprise notes | GA или версии моделей; записи с preview исключаются. Если дневная запись смешивает GA и preview, применяется строгий фильтр всей записи. |
| Vertex AI notes | Требуется название модели с версией. |
| AWS GenAI | Bedrock, AgentCore, Nova, open-weight или is now available. Nova добавлена как исключение для собственных моделей AWS. |
| AWS News | AI-слова и собственные AI-продукты/железо. |
| AWS What's New | Bedrock, SageMaker, Nova, Amazon Q, AgentCore, Trainium. |
| Azure AI | Анонсы; стратегические колонки без собственного события не проходят. |
| Foundry | What's new принимается как обновление платформы; остальные записи проходят общий отбор. |
| Azure Updates | Только заголовок `[Launched]` с OpenAI, Foundry, model или agent. |
| Vercel | AI Gateway, v0, AI SDK, agent; доступность моделей — только как «Где взять». |
| AI SDK releases | Только стабильные `ai@N.0.0`, N ≥ 1. Пакеты `@ai-sdk/*`, minor/patch и prerelease исключаются. Разные мажорные релизы не объединяются по корню репозитория. |
| Cloudflare AI | Собственные модели и платформенные анонсы Workers AI; чужие модели — как доступность. |

Кейсы клиентов, How X built/uses, how-to, вебинары, GovCloud, новые регионы и сертификаты исключаются. Проверка намеренно консервативная: нераспознанный продуктовый анонс не проходит как отдельный пост. Новые правила применяются при построении ленты и отборе для Telegram, поэтому смена правил перерабатывает уже собранный архив без повторных запросов к сайтам.

## Частота сбора

AWS What's New и Azure Updates проверяются раз в 30 минут, прочие облачные ленты — раз в час, пакетные релизы AI SDK — раз в 6 часов. Сохраняется положительный jitter. Между запросами к AWS и Microsoft минимум 30 секунд, Google Cloud/Vercel/GitHub/Cloudflare — 20 секунд. Существующие правила Reddit, Retry-After и растущий backoff сохраняются. Первые запросы новых источников разнесены по фоновому расписанию; одновременной принудительной проверки всех URL нет.
