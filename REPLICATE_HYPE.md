# Replicate Hype

Источник: https://hype.replicate.dev/. Используется публичный JSON API `/api/posts?filter=past_week&sources=github,huggingface,replicate,reddit`, без токена Replicate. Это дополнительный агрегатор, а не замена прямым источникам. Устройство API и значения полей проверены по [маршруту API](https://github.com/replicate/hype/blob/main/src/endpoints/posts.ts) и [сборщикам Hype](https://github.com/replicate/hype/blob/main/src/fetchers.ts).

Сборщик запрашивает один недельный список каждый час, с положительным jitter. Кэш — 30 минут. Каждый запрос использует существующие ограничения частоты, Retry-After, backoff и сохранённый ответ при сбое. При открытии дашборда запросов к Hype нет. Дополнительные запросы к каждой модели или репозиторию не выполняются. API Hype ограничивает список 500 записями; это не полный архив всех платформ.

Записи разделяются по исходной платформе:

| Платформа | Колонка | Поле `stars` в Hype | Дата `created_at` в Hype |
|---|---|---|---|
| GitHub | Репозитории | Звёзды за всё время | Создание репозитория |
| Hugging Face | Модели | Лайки | Последнее изменение модели |
| Replicate | Модели | Запуски за всё время | Создание последней версии |
| Reddit | Сообщество | Апвоуты | Публикация поста |

Запуски Replicate показываются как `runs`, но не прибавляют баллы популярности: для этой единицы пока нет настроенного порога. Общие звёзды GitHub не превращаются в прирост за сутки и не попадают в сортировку по `stars_day`. Лайки HF дают популярность как процентиль среди лайков Hype за 7 дней; trendingScore из Hype не придумывается.

Дата получения ответа не заменяет дату события. Для моделей из Hype интерфейс показывает «обновлено», а не дату создания или заявление о новом релизе. При объединении с прямой карточкой сохраняется общая логика выбора представителя и даты сюжета; повторное появление в агрегаторе не делает старую модель новой.

Для репозиториев работают ключевые слова и исключения проекта. Модели проходят общие исключения. Reddit проходит прежние пороги рейтинга, ключевые слова и правила сабреддитов. Hype не отдаёт флер: такие записи r/LocalLLaMA исключаются, поскольку подтвердить разрешённый флер нельзя. Условия отбора не обходятся через агрегатор.

Совпадения с прямыми GitHub/HF/Reddit объединяются по ссылке. Hype не считается ещё одной независимой площадкой для той же исходной публикации. Источник можно отключить через `enabled: false` у `replicate_hype` в `config.json`.

Диагностика без внешнего запроса:

```sh
docker compose exec worker python source_diagnostics.py --source 'Replicate Hype'
```

При необходимости добавьте `--probe`: запрос всё равно соблюдает кэш и cooldown.
